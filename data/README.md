# Data folders

- `paper_input/`: curated input files used by the main paper workflow.
- `api_test_input/`: small example files from the optional API pre-workflow.
- `preparation_input/`: intermediate files used during optional filtering and manual screening.
- `validation_templates/`: manual screening templates and label files used by the optional preparation workflow.

The main paper analyses use `paper_input/`. The other folders are kept for transparency and testing.

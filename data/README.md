# Data folder

This folder contains the curated data files needed to reproduce the manuscript workflow and a small set of upstream preparation files that document how the candidate video pool was filtered.

## `paper_input/`

Main analysis inputs used directly by the scripts:

- `videos_validated.csv` (**final LABEL dataset**): final validated video-level dataset used by the main analysis scripts; 1,899 rows and 1,895 unique videos.
- `comments_timestamped.csv` (**comments sensitivity input**): timestamped comments and replies used for the comments-only sensitivity analysis.

## `preparation_input/`

Upstream files documenting the filtering and labelling path:

- `api_regioncode_raw.csv` (**RAW-REG**): full region-code video pool after deduplication; 16,844 unique videos.
- `api_regioncode_raw_flagged.csv` (**RAW-REG flagged**): same RAW-REG pool with an `is_iberian` flag.
- `api_regioncode_postfiltered_candidates.csv` (**REG post-filtered candidates**): clean candidate REG file after language and Iberian locality filters; 6,935 unique videos.
- `api_regioncode_labelled.csv` (**REG-labelled**): REG videos labelled as Iberia-relevant; 1,884 unique videos.
- `api_geotagged_anchor_reconstructed.csv` (**GEO anchor reconstructed / reconstructed RAW-GEO**): geotag/location-based anchor recovered from older source-flagged working files; 305 unique videos.
- `preparation_input_manifest.csv`: file-level manifest with row counts and short descriptions.

## `api_test_input/`

Small optional API-test files generated by the public optional API pre-workflow. These are retained for demonstration/testing only and should not be interpreted as the full historical search outputs used to build the manuscript dataset.

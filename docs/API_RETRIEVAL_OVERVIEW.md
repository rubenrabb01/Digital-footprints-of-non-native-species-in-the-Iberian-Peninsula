# YouTube API retrieval overview

The repository reproduces the manuscript analyses from curated analytical datasets. The YouTube Data API retrieval strategy is described in the manuscript and Supplementary Methods, including the use of scientific and vernacular search terms, GEO and REG retrieval modes, publication-date limits, API result limits, post-filtering, manual Iberia-relevance validation, and deduplication.

Because YouTube search results, metadata, comments, availability, and ranking can change over time, the analyses should be reproduced from the frozen analytical corpus provided in `data/paper_input/`, together with the supporting species, search-term, preparation, and validation files included in the repository.

The repository also includes a minimal illustrative API example in `optional_youtube_api_example/`. This example shows the structure of a single YouTube Data API request in R using a placeholder API key and one example query. It is intended only as a simple demonstration of the API request structure; the manuscript analyses are reproduced from the curated analytical datasets.

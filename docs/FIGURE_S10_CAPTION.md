# Figure S10 caption

**Figure S10. Symmetric ±3-year sensitivity analysis of thematic keyword composition around species-specific first records.** Bars show the proportion of classified title and description keyword tokens assigned to each thematic category during the three years before and three years after the official first-record reference date. The analysis uses the same dictionary-based token classification as the main title-and-description workflow, but restricts records to a symmetric temporal window around each species-specific first record. The figure is intended as a supplementary sensitivity check for the descriptive pre-/post-introduction comparison, not as evidence of operational early warning.

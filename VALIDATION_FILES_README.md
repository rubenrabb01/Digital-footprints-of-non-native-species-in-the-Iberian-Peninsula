Validation files and figures

This package contains the validation-audit workflow used during revision.

Main locations:

- `outputs/validation/validation_files_by_validator/`: reviewer-specific CSV templates to send to validators.
- `outputs/validation/completed/`: consensus placeholder/completed files used by the workflow when available. Replace these with the real consensus files after all reviewer returns have been checked.
- `outputs/validation/completed/validation_files_by_validator/`: recommended location for real returned reviewer files.
- `outputs/validation/example_completed_files/`: artificial completed examples for testing only. Do not use these values in the manuscript or Supplementary Material.
- `outputs/validation/tables/`: validation metrics, agreement summaries, confusion matrices, and figure index generated by the audit script.
- `outputs/figures/validation/`: validation figures generated by `scripts/17_validation_summary_figures.R`.

Recommended run:

```r
source("scripts/99_run_validation_audits.R", encoding = "UTF-8")
```

This runner sources `scripts/15_validation_audits.R` and then `scripts/17_validation_summary_figures.R`.

## Returned validation files: folder compatibility

The workflow now supports both the older private reviewer-name folder structure and the newer anonymised validator folder structure. This means that completed files can be placed in either of the following locations:

```text
data/validation_input/completed/validation_files_by_reviewer/
data/validation_input/completed/validation_files_by_validator/
outputs/validation/completed/validation_files_by_reviewer/   # legacy fallback
outputs/validation/completed/validation_files_by_validator/  # legacy fallback
```

The original reviewer-name folders from the earlier workflow are retained for compatibility:

```text
Ana/
Gabriel/
Loreto/
Valerio/
```

The anonymised public-facing folders are also available:

```text
Reviewer_A/
Reviewer_B/
Reviewer_C/
Reviewer_D/
```

The script `scripts/15_validation_audits.R` normalises both older column names (`review_id`, `reviewer2_*`) and newer column names (`validation_id`, `validator2_*`). Therefore, once the completed CSV files are returned, you only need to replace the placeholder/example files with the completed files and run:

```r
source("scripts/99_run_validation_audits.R", encoding = "UTF-8")
```

This regenerates the validation summary tables and validation figures.

## Validation figures generated

The validation runner creates the following supplementary validation figures:

```text
outputs/figures/validation/Figure_S9_LABEL_validation_outcomes.png
outputs/figures/validation/Figure_S10_LABEL_validation_metrics.png
outputs/figures/validation/Figure_S11_keyword_validation_performance.png
outputs/figures/validation/Figure_S12_keyword_validation_confusion_matrix.png
```

Suggested manuscript/Supplementary Material interpretation:

- **Figure S9** summarises the outcome categories in the LABEL Iberia-relevance audit.
- **Figure S10** summarises LABEL audit metrics such as confirmed/uncertain/non-Iberia-relevant outcomes and agreement statistics.
- **Figure S11** summarises keyword-validation performance using precision, recall, and F1 by thematic category.
- **Figure S12** shows the keyword-validation confusion matrix comparing dictionary categories with manual validation categories.

These figures are generated from placeholder/example files until the final returned reviewer files are inserted. Final manuscript values should be updated only after the real completed validation files have been checked.
